# heavy jobs on one host queue for memory, not for a slot count

lexray's test queue counted runs and nothing else took part, so on 2026-11-15 four CI runs filled
zeus twice. `heavy-slot` admits a job when its memory fits the host's budget (MemTotal minus a
12G reserve, checked against MemAvailable too), first come first served, and the kernel releases
a reservation however its holder exits.
