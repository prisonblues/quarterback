# a fix pass is no longer told it ignored findings nobody sent it

The panel's payload lists every master-confirmed finding under `to_fix`, and it is the
report that cuts that list down to the one a fixer is actually handed — the rows below
`fix_severity_floor` are printed separately, under "Reported, not this round's work".
The round that read a payload back did not make that cut, so wherever the applied fix
floor reaches above the bottom band — a raised `fix_severity_floor`, or a
`low_severity_fix_lines` of zero, which lifts the applied floor to the trigger floor
because a band that can buy nothing is not this round's work — it treated every
confirmed finding as work the last fix pass had been briefed on.

Two things followed from that, and both were addressed to a human. A pass that had
answered exactly what it was asked to was reported as having left sub-floor findings
untouched — which `panel-review-pr.md` reads as the fixer's brief not being followed,
and asks the orchestrator to relay. And the revert proposal, whose cost column is
documented as a ceiling on what undoing the pass would give back, counted every one of
those findings as something the revert would cost. Measured on a cycle whose fix pass
was sent three findings and answered three: the round named sixteen it had never seen.
