# The panel's judge says what each finding is: a regression, a claim miss, or an observation

Every finding used to be priced only by severity, so a change that broke something, a
change that did not do what it claimed, and a remark about style or generality all bought
rounds alike. The judge now types each verdict as `regression` (something that worked no
longer does, shown by a failing check or a concrete wrong output), `claim_miss` (the
change does not do what it says it is for, with the claim quoted) or `observation`
(everything else, and the default). A regression or claim miss given without evidence is
counted as an observation, and the judge's own word is kept as `kind_said`. Each finding
in the payload carries `kind`, `kind_said` and `evidence`, the To fix list tags each row
with its kind, and a line under it counts them.

The type now decides what blocks. An observation is listed under **Observations, not
blocking**, buys no round at any severity, adds no class-ledger strike, is left out of
`fix_injection`, and cannot be filed as an issue (`panel_classes.py file` refuses a class
with no sighting typed regression or claim miss). A demonstrated regression or claim miss
blocks at any severity, under every floor. A finding with no type keeps the severity
floors it had, so old payloads read as before. A round left with only observations now
counts as converged.
