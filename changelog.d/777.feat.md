# the seats stop asking for code that should not have been written

Every lever this loop had for fix-pass churn acted on the fixer at the moment it wrote: the fix
severity floor, the line budgets, the surface rule, the re-review gate. All of them are downstream
of a finding that has already been raised, judged and briefed. Nothing acted on the finding itself,
and the finding is where the churn is cheapest to stop — one never raised costs nothing to fix,
nothing to judge, and cannot write the next round's findings. The numbers behind that: 128 of 201
new findings across seven PRs were written by the fix pass immediately before them, and no cycle on
record has ever been marked converged (0 of 27).

**One class of finding is now dropped at review time rather than downgraded.** A finding whose fix
would add bloat: a defensive check for a case that cannot happen, an abstraction used once, a
comment restating the code beside it, a test asserting a tautology, a just-in-case guard, an error
handler for a case the types already rule out. Not at a lower severity and not "for consideration"
— not raised at all. Downgrading buys nothing: whether a P4 reaches a fixer depends on a dial, and
below the floor it is still a verdict the judge spends, still a row in the payload and still an
outstanding item returned to the board unfixed. A finding raised at any severity has already cost
most of what raising it costs.

**It narrows what is worth reporting and never what is worth reading**, and the seat prompt says so
in its own words, because it sits under an opening that tells a seat to report everything it spots
and not to self-censor a minor finding. Left to resolve that itself a model resolves it whichever
way it likes, and the way that hurts is a seat quietly dropping real craft defects as "bloat". What
is dropped is the *proposal to add*; a defect the seat found is still reported however minor. Where
a dropped one is still worth somebody knowing, it is one `could_not_assess` phrase and nothing
more — which is not free, since every declaration costs the round a coverage line, and that is why
the offer also calls it rare. The move-manifest prompt deliberately does not get the paragraph: its
first question asks a seat to report a dropped guard clause as a P1, and a drop list whose third
item is "just-in-case guards" sitting under that question is a contradiction in a prompt whose
whole design is to keep a seat on four questions.

**And the fixer gets the mirror of it: sound + correct + elegant, all three.** Having named who
consumes the code it is about to change, the fixer asks whether applying the finding would leave
the code more sound, more correct *and* more elegant. A change that improves one of the three — or
degrades elegance to nominally improve correctness — leaves the codebase worse than it found it.
**Two out of three is a signal to look harder for a fix that gets all three, never a licence to
ship the two.** A finding that fails the bar is pushed back on with a reason rather than
mechanically applied, and the push-back is recorded as a `refuted` row with its reason in the
existing summary table — no new word to reach for, and one line to write, which is the point:
complying with a wrong finding must not stay cheaper than disproving it.

**Confirmation by the judge does not exempt a finding from that bar**, and the panel brief now says
so. The judge rules on whether a finding is *true*, never on whether applying it leaves the code
better, and reviewers bias toward recommending additions whether four seats raised something or
one. So the fixer is not told the list is pre-approved and is not asked for every item back as
`fixed`.

**A last pass over the finished diff**, joined to the existing verify step: re-read the whole diff
and revert any fix that turned out to be bloat in context. A green suite proves the code runs and
says nothing about a fix that works and should never have been written, and the finished diff is
the only place that is visible. A fix reverted there is a finding refuted late, and it is recorded
the same way.

Prompt text in the seat brief and the fixer brief, with no dial anywhere — there is no threshold
here to calibrate, and it sits upstream of every budget this loop has.
