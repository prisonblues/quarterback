The antigravity panel seat can run commands. With `reviewers.antigravity.tools` on (the new default) it reviews from a throwaway, instruction-stripped copy of the PR's tree with `agy --dangerously-skip-permissions`. The database variables point at an unresolvable host and `gh` has no credentials, and the round's notes say the seat had a shell. Previously a model that reached for a tool had the call auto-denied, which ended the session with no output and lost the seat for the round. `"tools": false` restores the diff-only seat.
