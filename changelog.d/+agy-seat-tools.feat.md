The antigravity panel seat can run commands. With `reviewers.antigravity.tools` (default true), it reviews from its own copy of the PR's tree with `agy --dangerously-skip-permissions` and an allowlisted environment. That prevents accidents but is not a sandbox: see the loops README. Its prompt now goes on stdin, so the 128 KiB argv cap that truncated antigravity on large diffs is gone, and with it the per-seat clamp.
