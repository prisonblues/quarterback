The antigravity panel seat can run commands. With `reviewers.antigravity.tools` on (the new default) it runs `agy --dangerously-skip-permissions` and is pointed at a throwaway, instruction-stripped copy of the PR's tree. Its environment has the database variables pointed at nothing, and `gh`, inherited credentials and the ssh agent removed. That prevents accidents but is not a sandbox. The summary's Code access line says when a seat had a shell. Previously a model that reached for a tool had the call auto-denied, which ended the session with no output and lost the seat for the round. `"tools": false` restores the diff-only seat.
