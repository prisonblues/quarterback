# the collision index stops answering "coast is clear" about the wrong repository

`GET /active` is the call every CLAUDE.md on the fleet tells an agent to make before starting
work, and its own tool docstring says an empty result means the coast is clear. On lexray, with
three agents live in the checkout:

```
active(repo="prisonblues/lexray")  ->  {"agents": [], "subagents": []}
active(repo="lexray")              ->  pine-mist, pebble-frost, meadow-coral
```

The qualified spelling is the only one `plan_read`, `claim` and every other keyed surface here
accepts — a bare name is a 422 and the message teaches `owner/name` — so an agent orienting the
documented way asked the qualified question and was told nobody was there. Three separate
defects reached that one answer:

| where | what it was | what an agent read |
|---|---|---|
| `Lease.repo == repo` | raw equality over a column the lifecycle hook filled with the checkout *basename* | empty board, for the qualified spelling and for any capitals |
| the sub-agent half of `/active` | `repo=` never filtered it at all | every sub-agent on the fleet, listed as company in *your* repo |
| the `repo` parameter | any string accepted, `[]` returned | a clone URL answered as "nothing registered here" |

`app/repomatch.py` now holds that rule once, for all four reads on the board that take a `repo`
filter — `/active`, `/overlap`, `/worktrees` and `/landing`, the last two of which had written
their own copies. `owner/name` and a bare repository name are both accepted; anything else is a
422, because *an empty answer reads as "nothing gates anything here" when it means "I could not
tell what you asked about"*. Leases are matched by repository **name**, which is the only thing
the two shapes the column legitimately holds have in common; the match is therefore wide across
owners, which is the cheap direction for a collision index and is disclosed, since every row
carries the `repo` it matched on.

The write path is the other half. `qb-hook` reports the origin remote's `owner/name` rather than
its basename, and `POST /lease` folds a qualified spelling's case, so the column converges
instead of being folded over forever. The bare name is still accepted: it is what a checkout
with no GitHub remote genuinely has, and refusing it would take a heartbeat's whole lease — the
agent's entire presence on the board — away over an optional field.

One visible consequence, fixed with it: the dashboard's AGENTS repo cell is eleven columns
because `prisonblues/` separates nothing on a fleet whose repos share an owner, so a lease now
reporting the slug would clip every row to `prisonblue…`. The fold moved into `repo_cell`,
where all four tables get it, rather than into the one caller that had not needed it before.

**And the board stops holding agents in a repository called `cwd`.** The same report noted the
panel's review seats posting `repo: "cwd"`, `branch: "master"` and read it as an unexpanded
variable. It was not: a seat runs in a `git init` sandbox, the directory was named `cwd`, and
`master` is what `git init` picks — both values were true about a throwaway repo nobody else
could name. A checkout with no origin remote now reports no repo at all, and the sandbox
directory is named `seat`. A repo name a peer can ask `/active` about and be answered about is
worse than none.
