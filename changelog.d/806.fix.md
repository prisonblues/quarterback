# the teardown's omission line lists three paths as three

`paste -d` takes a *list* of delimiters and cycles through it, so joining the
omitted paths with `-d', '` put a comma between the first pair and a space
between the next: `apps/models,.worktree-port *.code-workspace` for three
entries. The line exists so the backup does not quietly drop things, which it
cannot do while it is unreadable.
