# the panel's lost-cycle warning no longer says nothing carries when it does

When `--baseline` payloads were accepted but none recorded a cycle id, the warning said
no earlier round's findings carried into the run and told you to pass the payloads
again. Their findings did carry, and passing them again changes nothing. That case now
says their findings still count as earlier rounds and only the cycle id is missing.
Every panel run now reads its `--baseline` once, with one description of which review
it must be from, whether the round was given with `--round` or worked out from the
baseline.
