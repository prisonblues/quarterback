# the panel's lost-cycle warning no longer sends you to repeat what just failed

When every `--baseline` payload was accepted but none recorded a cycle id, the warning
still said to pass every earlier round's payload with `--baseline`. Passing them again
gives the same loss, so that case now says the cycle cannot be recovered from those
payloads and to start a new one with `--new-cycle`. The round a panel run works out from
`--baseline` alone now reads its baseline with exactly the same review identity as an
explicit `--round`, so a check added to one cannot skip the other.
