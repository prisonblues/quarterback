# the panel's lost-cycle warning says what actually carried, for each cause

When a panel run cannot continue its PR's cycle, the warning now matches its cause.
Accepted `--baseline` payloads that record no cycle id still count as earlier rounds,
and the warning says so instead of claiming nothing carried. When every payload was
refused, it points at the notes that say why, instead of telling you to pass the same
payloads again. Every run reads `--baseline` once, naming the review by the same fields
`load_baseline` checks, whether the round came from `--round` or from the baseline.
