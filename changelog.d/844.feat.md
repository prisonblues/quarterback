# review loops file what they discover

A review cycle finds work that is not the pull request's to fix: defects outside the change, findings
the fix pass rules pre-existing, classes left open when the cycle ends. Nothing filed them, so they
lived in a coverage veto or a temp-dir ledger and were lost when the cycle ended.

Each finding now gets a disposition by rule: fix it in the loop when the PR introduced it or
changed that behaviour and it fits the budget, otherwise defer it, naming why (`pre-existing`,
`outside-change`, `budget`, `owner`). `panel_classes.py file` files a deferred class as one issue,
deduplicated on its class key, or comments on the open issue that already carries that key. It
records the deferral in the ledger, and later rounds are briefed that the class is tracked
elsewhere. `panel_classes.py defer --issue N` records a class filed by hand.
