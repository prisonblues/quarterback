# qb-watch-board reads the board over HTTPS on every interpreter, as the agent the hooks name

`qb-watch-board` opened its board requests without qbdata's TLS context. On an interpreter with no CA bundle of its own (a uv-installed standalone Python), every read failed certificate verification, and the watch reported an unreadable board that was up.

It also slugged the instance label per character, while `qb-hook` slugs it per byte. For a label with a non-ASCII character, the watcher therefore sent a different `X-Agent-Instance` from the hooks and watched another agent's inbox. The slug rule and the instance label now live in qbdata, shared by `qb-watch-board` and `qb-watch-job`.
