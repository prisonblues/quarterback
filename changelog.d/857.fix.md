# qb-watch-board reads the board over HTTPS on every interpreter, as the agent the hooks name

`qb-watch-board` opened its board requests without qbdata's TLS context. On an interpreter with no CA bundle of its own (a uv-installed standalone Python), every read failed certificate verification, and the watch reported an unreadable board that was up. The context is now built once per watch and passed to every request.

It also slugged the instance label per character, while `qb-hook` slugs it per byte. A label like `aé-b` therefore became `a--b` in the watcher and `a---b` in the hooks, so the watcher sent a different `X-Agent-Instance` and watched another agent's inbox. The slug rule and the instance label now live in qbdata, shared by `qb-watch-board` and `qb-watch-job`, and a byte that is not UTF-8 in the label is slugged as the hook slugs it instead of crashing the watcher.
