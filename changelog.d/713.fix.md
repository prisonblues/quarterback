# every route that works in place now claims the work it is doing

`create-worktree` owned the only automatic pickup in the harness, so a claim was taken by the
CHECKOUT and never by the command. Work done in place claimed nothing from beginning to end and
the plan went on offering it: measured on lexray on 2026-09-03 with three agents live in one
repo, `claims(repo_path=…)` empty for the whole of it and `lapsed_claims` empty too, so none had
ever been taken. `/fix-issue-here` was the sharpest case — its stated purpose is *no worktree, no
branch*, so it missed the claim path by construction.

`/fix-issue-here` now claims the issue before it researches and hands it back when it commits, and
`/review-pr` claims the PR before it launches its fixer and releases it when it relays. The review
claim passes `--no-plan-item`, so a released review no longer leaves the PR sitting open at rank 1
of the plan offering the next agent a review that already ran. Both claims are taken inside an
agent session, so ending the session releases them even when the brief does not reach its own
release step.
